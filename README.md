# Two Books on System Design for the AI Era

Written for a Manager, Data Specialist in commercial pharma who works on a Snowflake stack and
bridges business stakeholders and data engineering.

| Book | Folder | Focus |
|------|--------|-------|
| **Book 1: System Design for AI Systems** | `book1-ai-system-design/` | How whole systems are designed (compute, storage, messaging, reliability) and how AI components (model serving, RAG, agents, ML platforms, evaluation) fit in. |
| **Book 2: Data System Design for AI** | `book2-data-system-design-for-ai/` | Data architectures end to end: modeling, warehouses and lakehouses (Snowflake), ingestion, transformation, quality, governance, data products, semantic layers, and the data foundations for ML and GenAI. Includes a deep dive on commercial pharma data. |

Start with each book's `00-README.md` for the table of contents and reading paths.
`STYLE_GUIDE.md` describes the audience and chapter conventions.

Suggested order: if you need to ship data products this quarter, read Book 2 Chapters 1-8 first,
then Book 1 Chapters 1-5, then alternate. If you want the big picture first, read Book 1 cover to cover.
